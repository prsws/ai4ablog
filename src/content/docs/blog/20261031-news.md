**Reading process charts.** Two new Reference pages explain EPC charts, the
diagram style we use to map the eight use cases onto Pepa's Head, Arms and
people: [Reading EPC Charts](/reference/reading-epc-charts/) and a printable
two-page [EPC Cheat Sheet](/reference/epc-cheat-sheet/).

**Voice-corpus terms, version 1.1.** The terms for the "Oye Pepa!" recordings
are updated and in effect from 30 October:
[English](/general/oyepepa-terms-en/) · [Español](/general/oyepepa-terms-es/).
The earlier version 1.0 stays available. The
[Privacy Policy](/general/privacypolicy/) was updated to match.

**A tidier sidebar.** Each section now has a small icon, the New and Upd tags
use the Pepa colours, and a new "Code on GitHub" link opens our repositories in
a new tab.
